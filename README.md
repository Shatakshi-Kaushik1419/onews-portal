# 📰 OnlineNewsHub

OnlineNewsHub is a responsive, modern online news portal web application designed as a student web development project. It features breaking news tickers, trending stories, category-based filtering, live search capabilities, a newsletter subscription form, and a toggleable Dark/Light mode.

---

## 🚀 Features

* **Dynamic Date Display:** Automatically fetches and displays the current date in the header.
* **Breaking News Ticker:** Displays a marquee banner for urgent announcements and live highlights.
* **Interactive News Search:** Allows users to search through news headlines, categories, and descriptions instantly.
* **Category Filtering:** Filter articles dynamically across categories like *India*, *World*, *Technology*, *Sports*, and *Education*.
* **Read More / Read Less Toggle:** Expandable article view for reading full stories directly on the page.
* **Dark & Light Mode:** Seamlessly switch between themes with saved preferences for an optimized reading experience.
* **Newsletter Subscription:** Interactive email subscription form with validation feedback.
* **Fully Responsive:** Adapts fluidly to mobile phones, tablets, and desktop screens.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure (`header`, `main`, `section`, `article`, `footer`).
* **CSS3:** Flexbox, CSS Grid, media queries, smooth scrolling, and custom theme variables.
* **JavaScript (ES6):** DOM manipulation, event listeners, array filtering, and dynamic content toggling.
